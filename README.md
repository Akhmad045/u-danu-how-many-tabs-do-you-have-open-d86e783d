A program that answers "How Many Tabs Do You Have Open?" with a single digit: **1** — the author's honest count at the moment of writing, one tab open and nothing else. The one-tab answer: no hoard, no backlog, just the page in front of them.

## Run it

```sh
python3 main.py
```

This writes the one-digit answer to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
